# Lean Clean Grill website

Website for Lean Clean Grill: high-protein, 100% halal burgers, chicken, salmon, bowls and shakes.

It's a plain static site (`index.html`, `styles.css`, `images/`) with no build step, so it can be hosted for free on Vercel, Netlify or GitHub Pages. Food photos are cropped from the restaurant's menu designs.
