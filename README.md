# Lean Clean Grill website

Website for Lean Clean Grill: high-protein, 100% halal burgers, chicken, salmon, bowls and shakes.

It's a plain static site (`index.html`, `styles.css`, `images/`) with no build step, so it can be hosted for free on Vercel, Netlify or GitHub Pages. Food photos come from the restaurant's menu designs, upscaled 4x with Real-ESRGAN. `builder.js` powers the "Build your meal" nutrition calculator; `motion.js` runs the exploded-burger scroll scene, reveals and count-ups (layers in `images/split/`).
